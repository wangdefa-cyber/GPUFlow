# 阶段 5：算法、仿真控制与策略对比完善

- 日期：2026-11-22
- 状态：完成
- 目标：让调度实验可控、可比较、可解释

## 1. 新增能力

### 1.1 可步进仿真引擎

`SimulationEngine` 新增：

- `initialize()`：建立初始到达事件。
- `step()`：推进一个仿真事件时间批次。
- `finished`：当前实验是否结束。
- `result()`：结束后返回最终结果。
- 原有 `run()` 内部复用 `step()`，保持批量实验兼容。

步进结果 `EngineStep` 包含：

- 当前仿真时间
- 是否结束
- 等待、运行、完成、受阻任务数
- GPU、CPU、内存当前分配量
- 本次新增事件数

相同输入下，逐步推进和一次性运行生成相同事件序列、指标和结果哈希。

### 1.2 实时仿真控制

动态仿真页新增“实时步进控制”：

- 创建实时仿真。
- 开始 / 继续：每秒自动推进一个事件时间批次。
- 暂停：停止自动推进。
- 单步推进：只处理下一个事件时间批次。
- 运行到结束并保存：一次性推进剩余事件。
- 重置：丢弃当前未保存的运行状态。

完成后的实时仿真与其他实验一样写入 SQLite，可进入历史实验回看。

### 1.3 四策略同条件批量实验

新增 `execute_strategy_batch`：

- 一次加载并冻结任务和服务器快照。
- 对 FIFO、SJF、Priority、Best Fit 使用相同：
  - 任务集合
  - 服务器配置
  - 到达序列
  - 随机种子
  - 等待 SLA
  - 队头规则
- 四个实验分别保存。
- 每个实验保留独立结果哈希。

### 1.4 策略对比页

对比页现已支持：

- 一键运行四种策略。
- 手动选择至少两个兼容实验。
- 输入兼容性校验。
- 指标对比表。
- 指标柱状图。
- GPU 利用率时间曲线。
- 完成时间箱线分布。
- 事实型结果解读。
- 实验元数据和结果哈希查看。

兼容性键包含：

- 任务快照
- 服务器快照
- 随机种子
- 等待 SLA
- 跳过队头设置

不兼容实验不会进入图表和结论。

## 2. 对比指标

对比页展示：

- 平均等待时间
- 平均周转时间
- Makespan
- GPU 平均利用率
- CPU 平均利用率
- 内存平均利用率
- 完成率
- 超时率
- Jain 公平性指数

结果解读只做事实比较：

- 谁的平均等待最短
- 谁的 Makespan 最短
- 谁的 GPU 平均利用率最高
- 谁的公平性指数最高

不自动宣称某个策略在所有维度最好。

真实数据冒烟结果：

### 用户任务

| 策略 | 平均等待秒 | Makespan 秒 | GPU % | 完成率 % |
|---|---:|---:|---:|---:|
| FIFO | 500.00 | 10,800 | 25.434 | 100 |
| SJF | 500.00 | 10,800 | 25.434 | 100 |
| Priority | 500.00 | 10,800 | 25.434 | 100 |
| Best Fit | 500.00 | 10,800 | 25.434 | 100 |

默认示范集群容量充足，因此四种策略结果一致。这是合法的实验结果，不应人为修改配置制造差异。

### 20 个真实历史回放任务

| 策略 | 平均等待秒 | Makespan 秒 | GPU % | 完成率 % | 公平性 |
|---|---:|---:|---:|---:|---:|
| FIFO | 78.40 | 53,374 | 0.161 | 100 | 0.6278 |
| SJF | 74.35 | 53,374 | 0.161 | 100 | 0.6278 |
| Priority | 78.40 | 53,374 | 0.161 | 100 | 0.6278 |
| Best Fit | 78.40 | 53,374 | 0.161 | 100 | 0.6278 |

解释：

- SJF 降低了平均等待，但该样本的任务到达较稀疏，因此 Makespan 不变。
- 历史回放任务统一使用中性优先级 5，因此 Priority 与 FIFO 顺序相同。
- GPU 利用率低反映虚拟集群容量远大于样本需求，同时也说明历史回放时间跨度很长。
- 页面保留原始分配量、容量和利用率，避免只看百分比得出结论。

## 4. 当前限制

- 尚未实现 backfill、资源预留或高级抢占。
- GPU 型号仍严格匹配。
- 历史导入仍采用文件前部有界样本，尚未实现按时间/用户/GPU 类型分层抽样。
- Priority 对历史回放任务使用统一中性值 5。
- 公平性首版按用户计算 Jain 指数。
- 自动播放速度为固定 1 秒，不提供播放倍率。
- 对比结论是事实摘要，不是 AI 决策。
