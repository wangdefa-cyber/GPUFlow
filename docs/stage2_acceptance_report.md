## 5. 进入阶段 3 前需要确认

1. 首版是否接受“历史实例作为主要调度单元”的设计？
2. 首版是否坚持 GPU 型号严格匹配？
3. 首版是否坚持任务只能整体放置在一台服务器？
4. 原型默认使用全量数据还是确定性分层抽样？
5. 超时率是否接受“等待 SLA + 可选显式截止时间”的口径？
6. 公平性首版是否按用户计算 Jain 指数？
7. 采用深色科技风的管理后台原型是否符合课程展示目标？

## 6. 主要风险

| 风险 | 应对 |
|---|---|
| 历史数据缺失导致工作负载偏差 | 显式质量标记、抽样规则和来源说明 |
| SQLite 全量查询性能 | 分页、索引、预聚合和可选抽样 |
| Streamlit 重跑影响仿真 | 引擎与页面解耦，状态由运行控制器管理 |
| 指标口径被误读 | 公式版本化，已完成/未完成任务分开统计 |
| 原型阶段过早追求视觉 | 阶段 3 先完成可操作原型，再进行视觉优化 |
