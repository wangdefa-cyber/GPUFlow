4. 实现纯领域模型和资源向量约束。

7. 实现离散事件引擎。

## 6. 风险

| 风险 | 应对 |
|---|---|
| 会话状态在浏览器关闭后丢失 | 阶段 4 迁移到 SQLite |
| 全量历史预览变慢 | 原型限制行数；正式版分页和预聚合 |
| 用户把静态预检误认为仿真 | 页面持续显示“静态容量预检”阶段门 |
| 策略对比尚无数据 | 阶段 5 仅在真实实验完成后开放比较 |
| Windows 临时目录清理提示 | 记录为测试环境提示，不影响测试结果 |
