# GPUFlow 领域术语表

本表用于统一系统分析、设计、代码、数据库和界面中的业务语言。一个概念只使用一个规范名称。

## 数据与来源

| 规范术语 | 定义 | 避免使用 |
|---|---|---|
| 历史追踪数据 | 阿里巴巴公开 GPU Trace 中真实采集并发布的记录 | 模拟数据、实验数据 |
| 数据集版本 | 一次经过校验、导入并可被实验引用的历史数据快照 | 文件、批次（单独使用） |
| 导入批次 | 一次 CSV 分块导入的执行记录 | 数据集版本 |
| 机器规格 | `pai_machine_spec` 描述的历史机器容量 | 虚拟服务器 |
| 历史作业 | job 表中的提交单元 | 仿真任务 |
| 历史任务 | task 表中的任务角色及其资源计划 | 仿真任务 |
| 历史实例 | instance 表中的可运行实例 | 调度任务 |
| 传感器观测 | sensor 表中实例生命周期内的资源聚合观测 | 实时监控 |
| 机器指标观测 | machine_metric 表中实例生命周期内的机器级聚合观测 | 仿真利用率 |
| 系统配置数据 | 用户在系统中创建的服务器、集群和调度参数 | 历史数据 |
| 仿真生成数据 | 仿真引擎根据任务和策略计算出的分配、事件和指标 | 真实数据 |

## 集群与任务

| 规范术语 | 定义 | 避免使用 |
|---|---|---|
| 虚拟 GPU 服务器 | 用户配置的一台可被仿真分配资源的服务器 | 历史机器 |
| 集群配置 | 一组有版本的虚拟 GPU 服务器及其调度容量设置 | 集群数据 |
| 资源容量 | 单台服务器可提供的 GPU 当量、CPU 核数和内存 GB | 资源总量（含义过宽） |
| GPU 当量 | GPU 数量，历史百分比除以 100 后得到 | GPU 百分比 |
| 可调度任务 | 一个只能整体放置在一台服务器上的任务实例 | 作业、历史任务 |
| 工作负载集 | 一次实验中提交给仿真引擎的不可变任务集合 | 任务表 |
| 到达时间 | 任务在仿真时间线上进入系统的时刻 | 提交时间（需补充语境） |
| 预计运行时长 | 调度和仿真使用的任务持续秒数 | 实际运行时长 |
| 优先级 | 数值越高越优先的调度属性 | 序号 |

## 调度与仿真

| 规范术语 | 定义 | 避免使用 |
|---|---|---|
| 排序规则 | 从等待队列中选择下一个任务的规则，如 FIFO、SJF、Priority | 调度算法（含义过宽） |
| 放置规则 | 为已选任务选择服务器和多资源匹配方式的规则，如 First Fit、Best Fit | 排序策略 |
| 调度策略预设 | 一组固定排序规则与放置规则的组合 | 算法 |
| 等待队列 | 已到达但尚未获得资源的任务集合 | 待运行列表 |
| 调度决策 | 在某个仿真时刻选择任务、服务器和资源分配的事实 | 分配结果（含义过宽） |
| 资源分配 | 任务占用某服务器 GPU、CPU、内存的记录 | 资源使用率 |
| 仿真实验 | 固定数据版本、集群配置、工作负载集、调度策略和随机种子的可复现运行 | 仿真页面 |
| 仿真运行 | 一次仿真实验的实际执行实例 | 实验配置 |
| 仿真事件 | 仿真时间线上发生的提交、排队、调度、启动、完成、取消等事实 | 日志消息 |
| 仿真快照 | 某个仿真时刻的完整运行状态 | 事件日志 |
| 仿真时间线 | 由仿真事件和快照构成的过程记录 | 真实时间 |

## 评价

| 规范术语 | 定义 | 避免使用 |
|---|---|---|
| 等待时长 | 任务开始运行时间减到达时间 | 排队时间（可作同义词，但文档统一用等待时长） |
| 周转时长 | 任务完成时间减到达时间 | 完成时间 |
| Makespan | 从最早任务到达至最后一个任务完成的总时长 | 总运行时间 |
| 分配利用率 | 已分配资源随仿真时间的积分除以容量与 Makespan 的乘积 | GPU 使用率（必须限定口径） |
| 观测利用率 | 历史 sensor/machine metric 中记录的利用率 | 仿真利用率 |
| 完成率 | 已完成任务数除以实验任务总数 | 成功率（状态定义不同） |
| 超时率 | 超过配置等待 SLA 或任务截止时间的任务比例 | 失败率 |
| 公平性指数 | 按用户或分组计算的 GPU 资源分配 Jain 指数 | 公平度（口径不明） |
| 推荐证据 | AI 建议引用的真实指标、事件或配置 ID | 推荐理由（可含自然语言） |
