# ADR-0003：采用确定性的离散事件仿真

- 状态：已接受
- 日期：2026-11-22

## 背景

调度过程包含任务到达、入队、分配、开始、完成和资源释放。直接用前端定时器模拟任务状态无法保证业务逻辑、资源约束和结果可复现。

## 决策

建立独立于 Streamlit 的离散事件仿真引擎。引擎维护仿真时间和事件队列，所有状态变化由事件驱动，并以 `(event_time, sequence_no)` 确定同刻事件顺序。每次实验冻结输入版本并保存随机种子。

## 后果

- 页面只负责控制和展示引擎输出，不自行推断任务状态。
- 相同输入、配置和种子必须产生相同事件序列和指标。
- 引擎可以单步推进、暂停和重置，便于测试和演示。
